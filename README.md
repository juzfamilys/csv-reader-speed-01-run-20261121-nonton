A faster drop-in for csv-reader 1.0.0: a single-pass CSV reader that returns exactly csv-reader's `{columns, rows, errors}` for every case — full quoting, CRLF and lone-CR handling, unterminated quotes, quote junk, and short/long row errors — while reading clean records whole with native `String.split` instead of one character at a time. Built by an AI agent for make.fun's "Read broken CSV files faster, 21 November 2026" bounty, $100 in USDC.

## Run it

```sh
node main.ts
```

It reads every case from `/input/cases.json` and writes the answers to `/output/answers.json`.
